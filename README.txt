ISI PAKET
---------
- index.html              Halaman utama website
- style.css               Desain premium dan responsif
- script.js               Navigasi mobile, animasi ringan, dan tombol WhatsApp
- assets/                 Foto profil, foto akademik, logo GMIM, dan watermark foto Kantor Sinode GMIM

SEBELUM WEBSITE DIPUBLIKASIKAN
------------------------------
1. Buka file script.js.
2. Cari baris:
   const WHATSAPP_NUMBER = "628XXXXXXXXXX";
3. Ganti dengan nomor WhatsApp yang benar, gunakan kode negara 62.
   Contoh: 6281234567890
   Jangan gunakan tanda +, spasi, atau tanda hubung.
4. Simpan file script.js.

CARA MENJALANKAN DI KOMPUTER
----------------------------
- Ekstrak ZIP.
- Buka folder hasil ekstrak.
- Klik dua kali index.html untuk melihat website di browser.

CARA UPLOAD KE HOSTING
----------------------
Website ini adalah website statis; tidak memerlukan database, Node.js,
atau proses build.

NETLIFY
1. Ekstrak ZIP.
2. Masuk ke https://app.netlify.com/drop
3. Seret folder website (folder yang berisi index.html, style.css,
   script.js, dan folder assets) ke area upload.
4. Tunggu proses selesai. Netlify akan memberikan alamat website.

CPANEL / HOSTING BIASA
1. Masuk ke File Manager hosting.
2. Buka folder public_html.
3. Upload ZIP, lalu Extract.
4. Pastikan index.html berada langsung di public_html, bukan di dalam
   folder bertingkat.
5. Buka domain untuk memeriksa website.

VERCEL / GITHUB PAGES
- Bisa dipublikasikan sebagai static site tanpa build command.
- Pastikan root project berisi index.html dan folder assets.
